🔥 MicroTorch

A lightweight, zero-dependency tensor autograd engine & neural network framework built from scratch in pure Python.

GitHub Repository Author Profile Dev.to Article

⚡ Quickstart

Clone and train a multi-layer perceptron with AdamW in under 30 lines of code:

from microtorch import Tensor, Sequential, Linear, ReLU, MSELoss, AdamW

# 1. Define Model Architecture
model = Sequential(
    Linear(2, 8),
    ReLU(),
    Linear(8, 1)
)

# 2. Setup AdamW Optimizer with Decoupled Weight Decay
optimizer = AdamW(model.parameters(), lr=0.05, weight_decay=0.01)
criterion = MSELoss()

# 3. Training Loop (Reverse-Mode Topological Autograd)
x = Tensor([[0.5, -1.0], [1.5, 2.0]])
y = Tensor([[1.0], [3.0]])

for epoch in range(100):
    optimizer.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()
    optimizer.step()

print(f"Final Trained Loss: {loss.item():.6f}")

🏗️ Core Capabilities

⚡ Reverse-Mode Autograd

Dynamic computational graph construction with topological sort backward propagation across all tensor nodes.

📐 N-Dimensional Tensors

Full matrix multiplication (@), automatic broadcasting, and reduction operators (sum, mean).

🧠 PyTorch-Style nn Library

Drop-in modular abstractions: Module, Linear, Sequential, ReLU, Sigmoid, Tanh, and loss functions.

🚀 First-Class Optimizers

Includes SGD (with momentum), Adam (adaptive moments), and AdamW (decoupled weight decay).
